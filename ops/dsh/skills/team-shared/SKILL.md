# Shared VM105 workspace

- Treat sessions, workspaces, and provider settings as shared with approved team members.
- Work in `/srv/dsh/workspaces/team-shared` unless a user explicitly chooses another workspace.
- Read `HANDOFF-INFRASTRUCTURE-ADMIN.md` in that workspace before using the `infrastructure-admin` MCP.
- Inspect before changing files. Keep credentials, API keys, cookies, and tokens out of sessions and workspace files.
- Avoid destructive commands. Leave a concise handoff in the workspace when work spans sessions.
